# 힘 단위 변환기

Tkinter로 만든 GUI 프로그램으로, 입력한 힘을 `N`, `kN`, `kgf` 단위로 변환해 표시합니다.

## 프로그램 용도

- 힘의 입력 단위를 `N`, `kN`, `kgf` 중에서 선택합니다.
- 입력한 값을 다음 세 단위로 변환해 소수점 셋째 자리까지 표시합니다.
  - `N` (뉴턴)
  - `kN` (킬로뉴턴)
  - `kgf` (킬로그램힘)
- `초기화` 버튼으로 입력값과 결과를 지우고 입력 단위를 `N`으로 되돌립니다.
- 정상적으로 변환한 뒤 `결과 복사` 버튼을 누르면 `N`, `kN`, `kgf` 결과를 클립보드에 복사합니다.
- 입력 칸에서 Enter 키를 눌러 변환할 수 있습니다.

## 필요한 환경

- Python 3
- Python 표준 라이브러리의 `tkinter` 및 `math`
- GUI를 표시할 수 있는 데스크톱 환경

별도의 외부 Python 패키지는 사용하지 않습니다. 운영체제에 따라 Python 설치 시 Tkinter가 함께 설치되어 있어야 합니다.

## 실행 명령

명령 프롬프트 또는 PowerShell에서 Python 파일이 있는 폴더로 이동한 뒤 실행합니다.

```powershell
python force_converter.py
```

환경에 따라 `python` 대신 `py` 명령을 사용할 수 있습니다.

```powershell
py force_converter.py
```

실행하면 `힘 단위 변환기` 창이 열립니다.

## 정상 입력 예시

### 예시 1: N 입력

- 입력값: `10`
- 입력 단위: `N`
- 변환 결과:

```text
N: 10.000
kN: 0.010
kgf: 1.020
```

### 예시 2: kgf 입력

- 입력값: `1`
- 입력 단위: `kgf`
- 변환 결과:

```text
N: 9.807
kN: 0.010
kgf: 1.000
```

### 예시 3: kN 입력

- 입력값: `2`
- 입력 단위: `kN`
- 변환 결과:

```text
N: 2000.000
kN: 2.000
kgf: 203.943
```

공백이 포함된 숫자 입력은 앞뒤 공백을 제거한 뒤 처리합니다. 예를 들어 ` 10 `은 `10`과 같이 처리됩니다.

## 결과 복사

1. 숫자와 입력 단위를 선택합니다.
2. `변환` 버튼을 눌러 결과를 확인합니다.
3. `결과 복사` 버튼을 누릅니다.
4. 메모장이나 문서에서 붙여넣기(`Ctrl + V`)하면 다음과 같은 결과가 입력됩니다.

```text
N: 10.000
kN: 0.010
kgf: 1.020
```

변환 결과가 없거나 입력 오류가 있는 상태에서 `결과 복사`를 누르면 복사하지 않고 `먼저 올바른 값을 변환해주세요` 안내를 표시합니다.

## 오류 입력 예시

숫자로 변환할 수 없거나 유한하지 않은 값은 오류로 처리됩니다.

| 입력값 | 표시되는 메시지 |
| --- | --- |
| 빈 입력 | `오류: 숫자 값을 입력해 주세요.` |
| `abc` | `오류: 숫자 값을 입력해 주세요.` |
| `1,000` | `오류: 숫자 값을 입력해 주세요.` |
| `inf` | `오류: 숫자 값을 입력해 주세요.` |
| `nan` | `오류: 숫자 값을 입력해 주세요.` |

오류가 발생하면 기존 변환 결과 대신 오류 메시지가 표시됩니다.
