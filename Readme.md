# 힘 단위 변환기

Tkinter로 만든 GUI 프로그램으로, 입력한 힘을 `N`, `kN`, `kgf` 단위로 변환해 표시합니다.

## 프로그램 용도

- 힘의 입력 단위를 `N`, `kN`, `kgf` 중에서 선택합니다.
- 입력한 값을 다음 세 단위로 변환해 소수점 셋째 자리까지 표시합니다.
  - `N` (뉴턴)
  - `kN` (킬로뉴턴)
  - `kgf` (킬로그램힘)
- `초기화` 버튼으로 입력값과 결과를 지우고 입력 단위를 `N`으로 되돌립니다.
- 정상적으로 변환한 뒤 `결과 복사` 버튼을 누르면 `N`, `kN`, `kgf` 결과를 클립보드에 복사합니다.
- 입력 칸에서 Enter 키를 눌러 변환할 수 있습니다.

## 필요한 환경

- Python 3
- Python 표준 라이브러리의 `tkinter` 및 `math`
- GUI를 표시할 수 있는 데스크톱 환경

CSV 분석기의 그래프 기능에는 외부 Python 패키지 `matplotlib`이 필요합니다.
운영체제에 따라 Python 설치 시 Tkinter가 함께 설치되어 있어야 합니다.

## 하중 데이터 분석

원본 입력 파일은 읽기만 하며 덮어쓰지 않습니다.

### 입력 CSV 형식과 단위

입력 파일 이름은 `load_data.csv`이고, 첫 번째 행의 열 이름은 다음과 같아야 합니다.

```text

```

- `time_s`: 시간, 단위 `s`
- `force_N`: 하중, 단위 `N`

각 값은 유한한 숫자여야 합니다. 응력은 `N/mm²`를 `MPa`로 사용해 다음과 같이 계산합니다.

```text
stress_MPa = force_N / area_mm2
```

## GUI 하중·응력 분석기

`load_analyzer_gui.py`는 CSV 파일을 선택하고 단면 치수를 입력해 하중과 응력을
화면에서 분석하는 Tkinter GUI입니다. 기존 `load_analyzer.py`의 CSV 읽기 및 데이터
검증 함수(`read_load_data`)를 사용합니다. GUI 분석 결과는 파일로 저장하지 않고
화면의 최대 응력 정보와 그래프로 표시합니다.

### 필요한 라이브러리와 설치

- Python 3
- Python 표준 라이브러리: `tkinter`, `csv`, `math`, `pathlib`, `typing`
- 외부 라이브러리: `matplotlib`

`tkinter`는 Python 설치에 포함되는 표준 GUI 라이브러리이지만, 운영체제나 Python
배포판에 따라 별도 설치가 필요할 수 있습니다. GUI를 표시할 수 있는 데스크톱
환경도 필요합니다.

`matplotlib`이 설치되어 있지 않다면 다음 명령을 실행합니다.

```powershell
python -m pip install matplotlib
```

### 실행 명령

프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
python load_analyzer_gui.py
```

### GUI 사용 순서

1. `CSV 찾아보기` 버튼을 눌러 CSV 파일을 선택합니다.
2. 선택한 파일의 유효 데이터 수와 제외된 행 수를 확인합니다.
3. 단면 종류를 선택합니다.
4. 선택한 단면에 필요한 치수를 입력합니다.
5. 단면적 표시를 확인하고 `분석` 버튼을 누릅니다.
6. 최대 응력과 해당 시간, 시간-응력 그래프를 확인합니다.

CSV를 선택하기 전에는 분석할 수 없습니다. 단면 종류나 치수를 바꾸면 이전 분석
결과가 현재 입력으로 계산된 것처럼 남지 않도록 최대 응력 표시와 응력 그래프가
초기화됩니다.

### GUI CSV 형식과 단위

선택하는 CSV의 첫 번째 행은 다음 두 열과 정확히 일치해야 합니다.

```text
time_s,force_N
```

- `time_s`: 시간, 단위 `s`
- `force_N`: 하중, 단위 `N`

각 데이터 값은 유한한 숫자여야 합니다. 치수 단위는 `mm`, 단면적 단위는 `mm²`,
응력 단위는 `MPa`입니다. 응력은 다음 식으로 계산합니다.

```text
응력(MPa) = 하중(N) / 단면적(mm²)
```

단면적은 반올림하지 않은 값으로 응력을 계산하고, 화면에 표시할 때만 간단한 형식으로
표시합니다.

### 단면 종류와 계산식

모든 단면은 입력한 치수를 이용해 이상화된 단면적으로 계산합니다.

#### 사각형

- 입력 치수: 폭 `b`, 높이 `h`
- 단면적:

```text
A = b * h
```

- 유효 조건: `b > 0`, `h > 0`

#### 원형봉

- 입력 치수: 지름 `d`
- 단면적:

```text
A = math.pi * d**2 / 4
```

- 유효 조건: `d > 0`

#### 원형관

- 입력 치수: 외경 `D`, 두께 `t`
- 내경: `D - 2*t`
- 단면적:

```text
A = math.pi * (D**2 - (D - 2*t)**2) / 4
```

- 유효 조건: `D > 0`, `t > 0`, `2*t < D`

#### 사각형관

- 입력 치수: 외측 폭 `B`, 외측 높이 `H`, 두께 `t`
- 단면적:

```text
A = B*H - (B - 2*t)*(H - 2*t)
```

- 유효 조건: 모든 치수가 0보다 크고, `2*t < B`, `2*t < H`
- 모서리 곡률은 무시하고 직각 모서리를 가진 이상화 단면으로 계산합니다.

#### H형강

- 입력 치수: 전체 높이 `H`, 플랜지 폭 `B`, 웹 두께 `tw`, 플랜지 두께 `tf`
- 단면적:

```text
A = 2*B*tf + (H - 2*tf)*tw
```

- 유효 조건: 모든 치수가 0보다 크고, `2*tf < H`, `tw < B`
- 필렛은 무시하고 직선으로 구성된 이상화 단면으로 계산합니다.

모든 입력값은 숫자로 변환할 수 있어야 하며 `NaN`, `inf`, `-inf` 같은 유한하지
않은 값은 허용하지 않습니다.

### GUI 오류 처리 규칙

- 치수가 비어 있거나 숫자가 아니거나 유한하지 않으면 분석을 진행하지 않고
  `모든 치수는 유한한 숫자로 입력하세요.` 안내를 표시합니다.
- 치수가 0 이하이면 분석을 진행하지 않고 `모든 치수는 0보다 큰 값이어야 합니다.`
  안내를 표시합니다.
- 원형관, 사각형관, H형강의 두께 조건을 만족하지 않으면 해당 단면의 조건을
  설명하는 안내를 표시하고 분석하지 않습니다.
- CSV를 선택하지 않았거나 선택한 CSV에 유효한 데이터가 하나도 없으면
  `먼저 유효한 데이터가 있는 CSV 파일을 선택하세요.` 안내를 표시하고 분석하지
  않습니다.
- CSV에 오류 행이 있으면 기존 검증 규칙에 따라 해당 행을 제외하고, GUI에 유효
  데이터 수와 제외된 행 수를 표시합니다. 오류 행의 구체적인 행 번호와 사유는
  기존 CSV 검증 함수가 출력합니다.
- 필수 열이 누락되었거나 열 이름이 정확히 `time_s,force_N`과 다르면
  `CSV 열 이름은 'time_s,force_N'이어야 합니다.` 오류를 표시하고 분석하지
  않습니다.

## 정상 입력 예시

### 예시 1: N 입력

- 입력값: `10`
- 입력 단위: `N`
- 변환 결과:

```text
N: 10.000
kN: 0.010
kgf: 1.020
```

### 예시 2: kgf 입력

- 입력값: `1`
- 입력 단위: `kgf`
- 변환 결과:

```text
N: 9.807
kN: 0.010
kgf: 1.000
```

### 예시 3: kN 입력

- 입력값: `2`
- 입력 단위: `kN`
- 변환 결과:

```text
N: 2000.000
kN: 2.000
kgf: 203.943
```

공백이 포함된 숫자 입력은 앞뒤 공백을 제거한 뒤 처리합니다. 예를 들어 ` 10 `은 `10`과 같이 처리됩니다.

## 결과 복사

1. 숫자와 입력 단위를 선택합니다.
2. `변환` 버튼을 눌러 결과를 확인합니다.
3. `결과 복사` 버튼을 누릅니다.
4. 메모장이나 문서에서 붙여넣기(`Ctrl + V`)하면 다음과 같은 결과가 입력됩니다.

```text
N: 10.000
kN: 0.010
kgf: 1.020
```

변환 결과가 없거나 입력 오류가 있는 상태에서 `결과 복사`를 누르면 복사하지 않고 `먼저 올바른 값을 변환해주세요` 안내를 표시합니다.

## 오류 입력 예시

숫자로 변환할 수 없거나 유한하지 않은 값은 오류로 처리됩니다.

| 입력값 | 표시되는 메시지 |
| --- | --- |
| 빈 입력 | `오류: 숫자 값을 입력해 주세요.` |
| `abc` | `오류: 숫자 값을 입력해 주세요.` |
| `1,000` | `오류: 숫자 값을 입력해 주세요.` |
| `inf` | `오류: 숫자 값을 입력해 주세요.` |
| `nan` | `오류: 숫자 값을 입력해 주세요.` |

오류가 발생하면 기존 변환 결과 대신 오류 메시지가 표시됩니다.
